# 巨藻圣殿 · Kelp Cathedral

一个用 WebGPU 实时渲染的奇幻海底场景。巨藻、岩石、珊瑚、沉船和水下光效都由程序生成，整个简体中文版装在一个 HTML 文件里。

- [下载 index.html](https://github.com/2391552910-coder/kelp-cathedral/raw/refs/heads/main/index.html)
- [查看原始提示词和后续要求](PROMPT.md)
- [下载 60 FPS 游戏录像（MP4，221 MB）](https://github.com/2391552910-coder/kelp-cathedral/releases/download/v1.0.0/kelp-cathedral-1080p60.mp4)。全片 60 秒，分辨率 1920 × 1080，3,600 帧由游戏逐帧渲染。

## 打开和操作

用支持 WebGPU 的 Chrome 或 Edge 打开下载的 `index.html`。点击**自由探索**手动飞行，或点击**自动漫游**观看完整的 60 秒路线。

| 操作 | 控制 |
| --- | --- |
| 移动 | W、A、S、D |
| 转动视角 | 鼠标 |
| 上浮、下潜 | Q、E |
| 加速 | 按住 Shift |
| 释放鼠标 | Esc |

**操作说明**菜单里有内置 GPU 基准测试。测试分别记录 GPU 耗时和浏览器帧间隔。
